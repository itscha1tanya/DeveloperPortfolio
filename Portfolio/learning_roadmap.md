# My Developer Learning Roadmap

**Name:** Chaitanya Verma  
**Course:** B.Tech CSE (AI/ML)  
**University:** K.R. Mangalam University

## Semester 1 – Foundations

- Learn Python programming fundamentals.
- Understand Linux commands and Bash scripting.
- Learn Git and GitHub for version control.
- Study HTML and CSS basics.
- Complete the Beginner Developer Ecosystem Portfolio.
- Explore basic API integration and JSON.

## Semester 2 – Core Development Skills

- Learn Data Structures and Algorithms.
- Study Database Management Systems and SQL.
- Improve HTML, CSS and JavaScript skills.
- Build beginner-friendly web development projects.
- Complete at least one industry-recognised certification.

## Semester 3 – Intermediate Development

- Strengthen problem-solving and coding skills.
- Learn Object-Oriented Programming in depth.
- Explore machine learning fundamentals.
- Work with Python libraries such as NumPy and Pandas.
- Build projects using real-world datasets.

## Semester 4 – AI and Machine Learning

- Study supervised and unsupervised learning.
- Learn data preprocessing and model evaluation.
- Explore deep learning fundamentals.
- Build practical AI/ML projects.
- Participate in hackathons and coding competitions.

## Semester 5 and Beyond – Career Preparation

- Explore advanced AI/ML and Agentic AI technologies.
- Develop full-stack and AI-powered applications.
- Contribute to open-source projects.
- Apply for internships.
- Build a strong technical portfolio.
- Prepare for technical interviews and placements.

## Long-Term Goal

My goal is to become a skilled software developer specialising in Artificial Intelligence and Machine Learning, capable of building practical solutions to real-world problems.
