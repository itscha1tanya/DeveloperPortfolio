## 2. Binary Number Representation

### Decimal 75 to Binary

Divide the decimal number by 2 repeatedly:

| Division | Quotient | Remainder |
|---|---|---|
| 75 / 2 | 37 | 1 |
| 37 / 2 | 18 | 1 |
| 18 / 2 | 9 | 0 |
| 9 / 2 | 4 | 1 |
| 4 / 2 | 2 | 0 |
| 2 / 2 | 1 | 0 |
| 1 / 2 | 0 | 1 |

Reading remainders from bottom to top:

**75 = 1001011 (Binary)**

### Binary 110101 to Decimal

Using positional weights:

= 1 × 2⁵ + 1 × 2⁴ + 0 × 2³
  + 1 × 2² + 0 × 2¹ + 1 × 2⁰

= 32 + 16 + 0 + 4 + 0 + 1

**110101 = 53 (Decimal)**
